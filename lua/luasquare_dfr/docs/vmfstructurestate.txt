This file describes "armature" or targetnames of component in VMF 'gm_darkfusion_v2' It may be standardized.

internalname entityclass 'targetname'(s) [notes]

for path_track, ('path_track' [direction as <>, > , <] 'another path_track') 
If path_track mentioned in the middle of the chain and is bi-directional left-and-right, 'next stop' is left, 'branch path' is right.
example: ('dfr_pt_stab_1' <> 'dfr_pt_stab_2' <> 'dfr_pt_stab_3')
    means   dfr_pt_stab_1 next stop is dfr_pt_stab_2.
            dfr_pt_stab_2 next stop is dfr_pt_stab_1, branch path is dfr_pt_stab_3.
            dfr_pt_stab_3 next stop is dfr_pt_stab_2.

The code should drive the tracktrain to destination node path_track while path_track send update whenever the tracktrain pass on it to lua and lua would stop the train when destination path track is reached.
